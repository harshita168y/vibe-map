# VibeMap 🌍✨

Real-time anonymous vibe sharing map built with Next.js, Supabase, and Mapbox.

VibeMap lets people instantly see the mood of places around the world — from crowded nightlife streets to quiet parks — through short anonymous vibe posts pinned live on an interactive map.

---

## Features

- 🌎 Interactive global vibe map
- ⚡ Real-time vibe updates using Supabase Realtime
- 📍 Location-based vibe posting
- 🏙️ Nearby place detection using Mapbox
- 🔍 Search cities, places, parks, hotels, bars, etc.
- 🌙 Full dark mode support
- 🫥 Anonymous posting
- 🚦 Rate limiting for spam prevention
- 📱 Mobile-first responsive UI
- ✨ Animated glassmorphism-inspired interface
